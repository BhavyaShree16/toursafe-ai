# 🤖 TourSafe AI Services

AI-powered services for tourist safety assistance and personalized travel guidance.

---

## Overview

This service uses AI workflows to generate personalized tourist safety briefings, weather-aware travel guidance, and contextual recommendations to enhance tourist safety during travel.

---

## Features

- Personalized safety briefings
- Weather-aware travel assistance
- Context-based safety recommendations
- Automated tourist onboarding support
- AI-powered response generation
- LangGraph workflow orchestration

---

## Tech Stack

- Python
- FastAPI
- LangGraph
- LangChain
- Groq API
